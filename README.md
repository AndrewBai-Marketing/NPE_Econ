# structnpe

**Estimate a joint Bayesian posterior from a model you can simulate.**

Supply a prior, a simulator, and a representation of the data. `structnpe`
trains a neural conditional density on simulated datasets, then returns
posterior draws for observed data. You can use those joint draws to calculate
parameter uncertainty and model-defined elasticities, profits, or policy effects.

[Get started](#get-started) · [Canonical example](#canonical-example-eight-schools) ·
[Theory and proofs](THEORY.md) · [Full benchmark evidence](BENCHMARKS.md)

## What is being estimated?

Let $\theta$ denote the structural parameters, $Y$ the data generated by the
model, and $S$ the data representation supplied to the estimator:

$$
\Theta\sim\pi,\qquad Y\mid\Theta=\theta\sim P_\theta,\qquad X=S(Y).
$$

For observed data $y_o$, the target is the **joint posterior conditional on
the chosen representation**:

$$
p(\theta\mid X=S(y_o))
=\frac{\pi(\theta)\,p_S(S(y_o)\mid\theta)}
{\int\pi(\vartheta)\,p_S(S(y_o)\mid\vartheta)\,d\vartheta}.
$$

The likelihood $p_S$ defines the target but need not be evaluated. Instead,
the estimator learns from prior-predictive pairs $(\theta_i,S(y_i))$ by
minimizing negative conditional log density:

$$
\widehat\phi\approx\arg\min_\phi
-\frac{1}{n}\sum_{i=1}^n\log q_\phi(\theta_i\mid S(y_i)).
$$

The implementation applies parameter transforms and training-split
standardization; the expression above is the equivalent objective in the
original parameter coordinates, up to a term independent of $\phi$.
The package now includes an experimental **conditional neural spline flow**,
adapting the autoregressive rational-quadratic architecture from our recent
stockpiling research: select `backend="spline"`. Both backends learn a joint
density in transformed parameter coordinates. The Gaussian-mixture estimator
(`backend="mdn"`) remains the default while the new flow is being validated.

The result is an approximate posterior, not a maximum-likelihood estimate.
It equals the full-data posterior only when the representation preserves the
relevant information **and** the learned density is accurate. The
[theory note](THEORY.md) states the population result, assumptions, and proofs.

## Get started

Python 3.11–3.13 is supported. From a repository checkout:

```bash
git clone https://github.com/AndrewBai-Marketing/NPE_Econ.git
cd NPE_Econ
python -m pip install ".[neural]"
python examples/custom_model.py
```

The [complete example](examples/custom_model.py) defines a prior and batched
simulator, trains an estimator, saves and reloads it, and estimates a normal
model's location and scale. Its small default budget demonstrates the workflow;
the numerical accuracy benchmark is below. Spline training and inference use
Torch and `nflows`; saved legacy MDN estimators retain NumPy-only CPU inference.

For your own model, the same interface is:

```python
from structnpe import ParameterSpec, StructuralModel, SummaryAdapter, fit

# Define prior(n, rng), simulator(theta, rng), and observed_data for your model.
model = StructuralModel(
    prior=prior,
    simulator=simulator,
    parameters=[ParameterSpec("preference"), ParameterSpec("cost", lower=0)],
    observation_adapter=SummaryAdapter(statistics=("mean", "std")),
    prior_id="my_model.prior.v1",
    simulator_id="my_model.simulator.v1",
)
estimator = fit(model, backend="spline", simulations=100_000, seed=1)
posterior = estimator.infer(observed_data, draws=20_000, seed=2)
print(posterior.summary())
joint_draws = posterior.to_dataframe()
```

The mean and standard deviation here are illustrative summaries. For a DDC
model, preserve information about choices, states, and purchase histories;
these two statistics will generally be insufficient.

## Canonical example: Eight Schools

The public `fit` interface estimates the population mean $\mu$ and
between-school standard deviation $\tau$ in the canonical partial-pooling
model. Integrating out the school effects gives

$$
y_j\mid\mu,\tau\sim\mathcal N(\mu,\tau^2+\sigma_j^2),\qquad
\mu\sim\mathcal N(0,10^2),\quad \tau\sim\operatorname{HalfNormal}(10).
$$

The simulator uses all eight reported effects as its representation. We compare
the learned hyperparameter posterior with independent numerical quadrature
under the same model, data, and prior. This established comparison uses
`backend="mdn"`: each of five fixed training seeds uses 50,000 simulations
and ten mixture components.

| Result | Population mean `mu` | Heterogeneity `tau` |
| --- | ---: | ---: |
| Deterministic quadrature posterior mean | 6.4720 | 4.7531 |
| `structnpe.fit`, average posterior mean over five MDN seeds | 6.4178 | 4.7042 |
| Range of the five fitted MDN posterior means | [6.0483, 6.9624] | [4.5063, 5.0521] |

All five runs pass the documented numerical comparison limits. The largest
marginal-CDF discrepancy is **0.04997**, the largest posterior-mean error is
**0.11701** reference posterior standard deviations, and the largest coarsened
joint-grid total variation is **0.06350**. The range in the table describes
variation across training runs; it is not a credible interval.

Reproduce the full comparison from this checkout:

```bash
python -m pip install ".[replication]"
python replication/eight_schools/run_validation.py --quiet
```

This is a posterior-accuracy check, not a speed advantage over quadrature.
It is development evidence on one dataset, not a general calibration result.
The [benchmark page](BENCHMARKS.md) includes every seed, priors, diagnostics,
commands, and limitations, including the weak dependence in this example.

**New spline backend:** it passes a conjugate-normal recovery test, seeded
save/load checks, and a test that each parameter can respond to observed data.
On three new Eight Schools fits, all posterior-mean errors are below 0.15
reference posterior standard deviations, but only one run passes every
distributional limit. One misses the joint-grid limit; another misses a
95% interval-endpoint limit. These results are reported separately in the
[spline comparison](BENCHMARKS.md#experimental-spline-backend). They do not
establish superiority over the MDN.

For a canonical economic DDC, the repository also includes **Rust bus
replacement**. Its successful simulation-trained grid comparison is
**not the generic `structnpe.fit` MDN**; the generic MDN's failed comparison is
retained there too. [Read the Rust comparison](BENCHMARKS.md#rust-bus-replacement-model).

## Practical guidance

- **Check the simulator before fitting.** Prior-predictive datasets should have
  plausible units, support, sample sizes, and observable patterns.
- **Treat the representation as part of the model.** Use `ArrayAdapter` to
  preserve a fixed-size observation array, or supply informative summaries.
  Increasing the neural network cannot recover information discarded by $S$.
- **Validate where you will use the estimator.** Compare with a tractable
  reference when available; examine fresh simulated datasets, repeated seeds,
  and recovery near the empirical fit as well as across the prior.
- **Calculate counterfactuals from joint draws.** Apply your model's economic
  function to each parameter draw, preserving dependence among parameters.
- **Reuse within the declared setup.** Changes to the prior, simulator, data
  design, or representation require a new fit or a justified correction.
  Changing `prior` to a targeted proposal does not automatically implement
  sequential NPE.

## Properties and scope

[THEORY.md](THEORY.md) provides statements and proofs for the log-score target,
conditional convergence, representation loss, parameter transformations,
counterfactual error bounds, and ideal Bayesian calibration. These are standard
statistical properties and their consequences for this implementation, not
claims of a new NPE algorithm or finite-sample guarantees for a trained network.

`structnpe` is an **experimental beta**. It is useful when simulations are
available and joint posterior inference is difficult, especially when the
trained estimator can be reused. It does not establish identification or model
correctness, and it does not remove the cost of solving a dynamic model.
